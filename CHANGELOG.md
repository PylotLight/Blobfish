# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [Unreleased]

### Added
- Expandable, draggable sidebar resizer with smooth mouse drag and double-click width toggling (persisted to localStorage).
- Custom high-resolution mascot logo and app icon for Blobfish.
- Polished welcome hero screen with direct connection trigger when no accounts are attached.

### Changed
- Shifted storage account and container action controls (pin, rename, delete, detach) to display on hover/focus only, unlocking 100% full row width for account and container names.
- Widened default sidebar width from 300px to 340px to give ample space for long storage account and container names.
- Cleaned up generic starter and template text across the app (updated tagline to "Azure Blob Storage Explorer", enhanced empty state cards, refined footer security badge).
- Upgraded the brand header with glowing mascot icon frame, gradient typography, and Azure badge.
- Replaced table header styling with rich frosted glass backdrop blur and fixed sticky positioning to eliminate row bleed-through and clipping during scroll.
- Increased font sizes across table headers, rows, crumbs, and sidebar items for clearer legibility and balanced proportions.
